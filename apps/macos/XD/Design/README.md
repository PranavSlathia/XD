# XD visual system — Evidence Sequencer

The selected source is `selected-option-3.png` (1487 × 1058). It is the third
displayed concept from the 2026-08-21 visual checkpoint and is the binding visual
target for the first native client.

## Reference translation

- **Structure:** 14% navigation, 25% attention list, 61% evidence detail. Native
  `NavigationSplitView` owns the three-column behavior.
- **Surface:** matte near-black canvas and charcoal panels. Separation comes from
  alignment and one-pixel rules, not floating cards or glass.
- **Type:** system sans for reading and system monospaced/tabular figures for
  state, dates, metrics, and compact labels.
- **State colour:** amber is attention, subdued green is pass/Ready, desaturated
  blue is Authority, and red is destructive Reject. Colour never carries state
  alone.
- **Interaction:** rows are full-width targets. Ready, Research, and Reject stay
  anchored at the bottom. Raw evidence is disclosed after the decision summary.
- **Truth model:** Name and Authority panels are independent. The interface never
  displays a compensating overall score.

SF Symbols provide interface icons. The selected screen contains no raster art,
illustration, texture, or custom brand mark requiring generated assets.
